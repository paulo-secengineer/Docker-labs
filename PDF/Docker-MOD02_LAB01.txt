Objetivo:

Criar e rodar um container Nginx e testar o acesso.

- Criar e executar um container Nginx em modo daemon (-d).
- Testar o acesso ao Nginx via navegador e terminal.
- Aprender a visualizar containers ativos e parados.

1 - Criar um container Nginx em segundo plano:
	docker run --name nginx_lab -d -p 8080:80 nginx

2 - Verificar se o container está rodando:
	docker container ls  # Mostra containers em execução
	docker container ls -a  # Mostra todos os containers, incluindo os parados
	docker ps  # Comando tradicional que lista containers ativos

3 - Testar o acesso ao Nginx: (Retire o espaço entre as barras duplas "//" e o "localhost")
	curl http:// localhost:8080

4 - Parar o container:
	docker stop nginx_lab

5 - Verificar se o container esta parado:
	docker container ls 
	docker container ls -a
